# Chrome 웹 스토어 등록 준비

업로드 파일: `dist/udemy-toolkit-2.0.0.zip` (`udemy-toolkit/` 안의 실행 파일만 담음. DESIGN.md·README.md·테스트는 제외, git에는 올라가지 않음).
다시 만들 때는 `udemy-toolkit/manifest.json`의 `version`을 올린 뒤 같은 방식으로 압축한다.

## 먼저 정할 것 (사용자 결정)
| 항목 | 상태 | 메모 |
|---|---|---|
| 개발자 계정 | 필요 | Chrome 웹 스토어 개발자 계정 등록(1회 등록비 5달러). 본인이 직접 해야 한다 |
| 확장 이름 | 변경함 | "Toolkit for Udemy"로 바꿨다(manifest, 팝업, 설정 화면). 영어 설명 첫 줄에 "Unofficial … not affiliated with Udemy"를 넣었다([web-store-listing-en.md](web-store-listing-en.md)) |
| 아이콘 | **위험** | 사용자가 고른 그림(브라우저 창 + Udemy 로고와 닮은 "U" 글자 + 렌치)으로 만들었다. **Udemy 로고와 닮아서 상표 침해·사칭으로 반려될 수 있다.** 반려되면 로고를 닮은 "U"와 모자 모양을 빼고 재생 버튼+렌치처럼 독자 디자인으로 바꾼다 |
| 화면 언어 | 영어 | 도구 막대·팝업·설정·알림이 모두 영어. 목록 설명도 영어 문구([web-store-listing-en.md](web-store-listing-en.md))를 쓴다 |
| 개인정보처리방침 URL | 필요 | 아래 "개인정보 응답" 내용을 공개 페이지(예: GitHub Pages나 저장소의 문서 링크)에 올려 URL을 넣는다 |
| 스크린샷 | 필요 | 1280×800 또는 640×400, 1~5장. `npm run shots`의 그림은 모의 화면이라 **실제 Udemy 화면 캡처**를 권장 (강의 영상·계정 정보가 나오지 않게 주의) |
| 소형 타일 | 필요 | 440×280 이미지 1장 (홍보 이미지는 선택) |
| 목록 언어 | 선택 | 설명 문구는 한국어 위주. 해외 사용자도 받으려면 영어 설명을 함께 올린다 |

## 한 가지 목적 설명 (Single purpose)
"Udemy 강의 학습을 편하게 해 주는 도구 모음: 내 강의 정리, 재생 도구(배속·자막·메모), 학습 기록." 기능이 여러 개라 반려될 수 있으니, 모두 Udemy 학습이라는 하나의 목적에 속한다고 설명한다.

## 권한 사용 이유 (등록 화면에 붙여 넣기)
- **storage**: 설정, 메모, 문장 수집함, 태그·학습 큐, 학습 기록, 코스별 배속을 저장한다.
- **unlimitedStorage**: 내 강의 목록·커리큘럼 캐시가 기본 한도(약 10MB)를 넘을 수 있다. 모두 이 브라우저 안에만 저장한다.
- **activeTab**: 사용자가 도구 막대의 Capture를 눌렀을 때 현재 영상 화면을 캡처한다(`tabs.captureVisibleTab`).
- **clipboardWrite**: 사용자가 누른 복사 동작(대본 복사, 캡처 이미지, 문장 복사)을 클립보드에 쓴다.
- **호스트 권한 `https://*.udemy.com/*`**: Udemy 강의 화면에 도구를 붙이고, 로그인한 사용자 본인의 강의 목록·진행률·자막 정보를 Udemy 서버에서 읽는다.
- **`https://udemy-captions.s3.amazonaws.com/*`, `https://*.udemycdn.com/*`**: Udemy가 자막 파일(VTT)을 내려 주는 주소. 이중 자막과 대본 복사에 쓴다.
- **선택 호스트 `https://translate.googleapis.com/*`**: 사용자가 설정에서 "기계번역"을 직접 켠 경우에만 요청한다(켜면 권한 요청 창이 뜸).

## 개인정보 응답 (Privacy practices)
- 수집·판매·광고 목적 사용: **없음**. 개발자 서버가 없고 분석(Analytics) 도구도 없다.
- 이 브라우저에 저장: 메모, 문장, 태그, 학습 기록, 강의 목록 캐시, 코스별 속도. 설정(단축키·옵션)은 크롬 동기화(chrome.storage.sync)로 같은 계정의 다른 PC와 공유될 수 있다.
- 외부 전송: **기계번역을 켠 경우에만** 현재 자막 문장이 구글 번역(translate.googleapis.com)으로 전송된다. 그 외에는 Udemy 서버에만 요청한다(사용자의 로그인 세션으로).
- 원격 코드 실행: **없음**(`eval`·원격 스크립트 없음, 모든 코드가 패키지 안에 있음).
- 데이터 사용 항목 체크: "웹 기록"/"웹사이트 콘텐츠"(Udemy 강의 자막·제목)는 **기능 수행에만 사용**, 제3자 판매·무관한 목적 사용·신용 평가 사용 모두 "하지 않음"으로 답한다. (등록 화면의 질문 구성은 바뀔 수 있으니 실제 문항에 맞춰 확인)

## 점검 결과 (2026-11-13)
- manifest: MV3, 설명 85자(한도 132자), 아이콘 16/32/48/128 존재, 참조 파일 31개 모두 존재.
- 원격 코드·`eval` 없음. 외부 주소는 Udemy 계열과 translate.googleapis.com(옵트인)뿐.
- zip 맨 위에 `manifest.json`이 있고 경로 구분자는 `/`.
- **확인하지 못함**: 실제 웹 스토어 심사 결과, 스크린샷 규격 충족 여부, 개인정보 문항의 최신 구성. 심사는 보통 며칠 걸리고, 권한(`https://*.udemy.com/*` 전체)이 넓어 추가 소명을 요청받을 수 있다.
