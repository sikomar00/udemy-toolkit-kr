# Chrome 웹 스토어 목록 (한국어)

이름과 요약은 `udemy-toolkit/_locales/ko/messages.json`에서 자동으로 들어갑니다.

요약(132자 이하): Udemy 이중 자막, 최대 16배속, 강의 대본 한 번에 복사, 내 강의 일괄 정리. 비공식·무료·오픈소스, 계정 필요 없음. 아래는 대시보드 "스토어 등록정보 → 언어: 한국어 – ko"의 설명 칸에 넣는 글입니다.

## 설명

Udemy로 공부할 때 쓰는 무료·오픈소스(MIT) 도구입니다. 비공식이며 Udemy, Inc.와 제휴하거나 승인·후원을 받지 않았습니다.

이런 분께 맞습니다.
- 배속, 자막, 강의 정리용 Udemy 확장을 여러 개 켜 두고 쓰는 분
- 【한글자막】 강의를 들으며 영어 원문도 같이 보고 싶은 분
- 강의 대본을 복사하려고 대본 창을 끝까지 스크롤하던 분
- Udemy의 2배속 제한이 답답한 분
- 사 둔 강의가 수백 개인데, 보관할 때마다 페이지가 새로고침되어 짜증났던 분

이중 자막
- 두 언어 자막을 동시에 보여 줍니다(영어 + 한국어 등). 강의에 두 언어 자막이 있을 때 동작하며, Udemy 자동 번역 자막도 포함됩니다. 보조 언어가 없으면 기계번역을 켤 수 있습니다(기본은 꺼짐).
- 어학 도구: 지금 문장 다시 듣기·반복(Q / L), 복사(Y), 번역과 출처 링크까지 저장(K). 저장한 문장은 Anki 덱이나 CSV로 내보냅니다.

배속·단축키
- 0.25~16배속. 강의별로 속도를 기억하고, Udemy가 속도를 되돌리면 다시 적용합니다.
- D / S 속도, Z / X 이동, N / P 다음·이전 강의, V 이중 자막, Alt+N 메모, Alt+S 캡처, Alt+P 화면 속 화면, Alt+T 넓게 보기, H 도움말. 모든 키를 바꿀 수 있고 Udemy 기본 키도 그대로 동작합니다.

대본·메모·캡처
- 강의 대본 전체를 버튼 하나로 복사. 자막을 TXT, SRT, Markdown으로(이중 자막 포함), 코스 전체 자막을 Markdown 한 파일로 내보내기.
- 그 초로 바로 가는 타임스탬프 메모(Markdown 내보내기), 화면 캡처, 화면 속 화면, 넓게 보기.
- 지금 배속 기준 섹션별 남은 시간, 섹션 전체 완료 한 번에 표시.

내 학습: 강의 수백 개 정리
- "내 강의 도구": 별점, 리뷰 수, 수강생 수, 시간, 진행률, 최근 업데이트, 구매일, 자막 언어로 정렬·필터. 태그, 학습 큐, 메모.
- 새로고침 없이 보관. 여러 강의를 골라(Shift+클릭으로 범위 선택) 한 번에 보관하고 되돌리기. CSV(Notion)·Markdown으로 내보내기.
- 검색 결과에 "보유 중" 표시로 같은 강의를 두 번 사는 일 방지.

학습 기록·설정
- 툴바 팝업에서 오늘 학습 시간, 목표, 연속 달성.
- 한국어·영어 화면(브라우저 언어를 따름). 키보드와 화면 낭독기로 사용 가능.
- 모든 데이터를 JSON으로 백업·복원.

개인정보
- 계정·광고·분석 도구·개발자 서버가 없습니다. 메모, 문장, 태그, 학습 기록은 내 브라우저에만 있습니다.
- 설정은 Chrome 계정으로 동기화될 수 있습니다. 기계번역을 켤 때만 자막 문장이 구글 번역으로 보내집니다.
