# Chrome 웹 스토어 목록 (한국어)

이름과 요약은 `udemy-toolkit/_locales/ko/messages.json`에서 자동으로 들어갑니다. 아래는 대시보드 "스토어 등록정보 → 언어: 한국어 – ko"의 설명 칸에 넣는 글입니다.

## 설명

Toolkit for Udemy는 비공식·독립 도구입니다. Udemy, Inc.와 제휴하거나 승인·후원을 받지 않았습니다. "Udemy"는 Udemy, Inc.의 상표입니다.

강의 화면 (플레이어)
- 0.25~16배속. 강의별로 속도를 기억하고 단축키로 조절합니다 (D / S / R, Z / X 앞뒤 이동, N / P 다음·이전 강의).
- 영상 바로 아래에 붙는 도구 막대: 이중 자막, 문장 반복, 대본 복사, 메모, 캡처, PiP, 넓게 보기, 자막 설정. 클릭 한 번으로 켜고 끕니다.
- 이중 자막: 두 언어 자막을 동시에 보여 줍니다. Udemy 자막이 영상 아래 띠에 나오면 그 자리를 원문 + 번역 상자로 바꾸고, 영상 안에 나오면 숨긴 뒤 영상 위에 두 줄로 보여 줍니다. 보조 언어 자막이 없으면 기계번역을 고를 수 있습니다.
- 어학 도구: 지금 문장 다시 듣기·반복, 문장 복사, 문장 수집함에 저장 (Anki로 내보내기).
- 강의 대본 전체를 한 번에 클립보드로 복사. 자막을 TXT, SRT, Markdown으로 내보내기 (이중 자막 포함).
- 타임스탬프 메모 (이 브라우저에만 저장), 섹션별 남은 시간, 섹션 전체 완료 표시, 화면 속 화면(PiP), 화면 캡처, 다크 모드(선택).
- 단축키로 모든 기능 사용 (D / S 속도, Z / X 이동, V 이중 자막, L 반복, Q 다시 듣기, Y 복사, K 문장 저장, Alt+N 메모, Alt+S 캡처, Alt+P PiP, Alt+T 넓게 보기, H 도움말). 모든 키를 바꿀 수 있고 Udemy 기본 키도 그대로 동작합니다.

내 학습·검색
- "내 강의 도구" 패널: 별점, 리뷰 수, 수강생 수, 강의 시간, 진행률, 최근 업데이트, 구매일, 자막 언어로 정렬·필터. 태그, 학습 큐, 메모, 일괄 보관, CSV·Markdown 내보내기.
- 체크박스를 Shift+클릭해 범위 선택, 가려진 강의가 있으면 알려 주는 안전한 전체 선택, 한 번에 되돌릴 수 있는 일괄 보관, 고른 강의만 내보내기.
- 마지막으로 본 탭·필터·정렬을 기억합니다.
- 강의 카드에 배지, 검색 결과에 "보유 중" 표시로 같은 강의를 두 번 사는 일을 막습니다.

팝업·설정·백업
- 키보드와 화면 낭독기로 쓸 수 있습니다: 이름 있는 대화상자, 패널 안에 머무는 초점, 읽어 주는 알림, 확인한 글자 색 대비.
- 화면은 영어와 한국어를 지원합니다. 기본은 브라우저 언어를 따르고, 설정 → 일반에서 고를 수 있습니다.
- 툴바 팝업에서 오늘 학습 시간, 지금 강의의 속도·남은 시간, 빠른 설정(이중 자막, 보유 강의 숨기기, 영상 아래 도구 막대, 다크 모드)을 봅니다.
- "화면 구조 점검"으로 Udemy 화면이 바뀌어 기능이 고장 났는지 확인하고 결과를 복사할 수 있습니다.
- 설정, 메모, 저장한 문장, 태그, 프리셋, 학습 기록을 JSON으로 백업·복원합니다.

학습 기록
- 하루 시청 시간, 목표, 연속 달성. 모두 이 브라우저에만 저장됩니다.

개인정보
- 계정·분석 도구·개발자 서버가 없습니다. 메모, 문장, 태그, 학습 기록은 내 브라우저에만 있습니다.
- 설정(단축키·옵션)은 Chrome 계정으로 동기화될 수 있습니다.
- 기계번역을 켜면 번역할 자막 문장이 구글 번역으로 보내집니다. 기본은 꺼져 있고, 켤 때 권한을 먼저 묻습니다.
