# Toolkit for Udemy v2.0

Udemy 내 학습 페이지, 강의 플레이어, 검색·강의 소개 페이지를 강화하는 개인용 크롬 확장입니다.
v1(정렬·필터)의 기능을 모두 포함합니다.

## 설치

1. 압축을 풀어 `udemy-toolkit` 폴더를 원하는 위치에 둡니다. 이 폴더를 지우면 확장도 사라집니다.
2. `chrome://extensions`를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `udemy-toolkit` 폴더를 선택합니다.
4. 기존 v1(`Udemy 내 강의 정렬·필터`)은 **삭제**합니다. 두 개를 같이 켜면 버튼이 2개 생깁니다.
5. 툴바 퍼즐 아이콘에서 Toolkit for Udemy를 고정하면 팝업을 바로 열 수 있습니다.

업데이트할 때는 같은 폴더에 새 파일을 덮어쓴 뒤, `chrome://extensions`에서 새로고침 아이콘을 누릅니다.

## 기능 요약

| 영역 | 기능 |
|---|---|
| 내 학습 | 별점·신뢰 별점(리뷰 수 보정)·리뷰·업데이트·시간·수강생·진행률·구매일·최근 접속·출시일로 정렬 |
| | 필터: 진행 상태, 최소 별점·리뷰·수강생, 시간 범위, 업데이트 기간, 카테고리, 강의 언어, 자막 언어, 구매 시기, 마지막 접속, 즐겨찾기, 학습 큐, 태그 |

| | 보관 안 됨 / 보관됨 / 전체 탭과 요약 통계(총 시간, 남은 분량, 미시작 수, 상위 카테고리) |

## 단축키 (영상 강의 화면, 설정에서 변경 가능)

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| D / S | 속도 + / − | R | 1배속 ↔ 이전 속도 |
| Z / X | 10초 뒤로 / 앞으로 | N / P | 다음 / 이전 강의 |
| Alt+P | PiP | Alt+T | 넓게 보기 |
| V | 이중 자막 켜기/끄기 | Q | 현재 문장 다시 듣기 |
| L | 현재 문장 반복 | K | 문장 수집함에 저장 |
| Y | 현재 문장 복사 | Alt+N | 타임스탬프 메모 |
| Alt+S | 화면 캡처 | H | 단축키 도움말 |

- **Udemy 기본 키는 그대로 동작합니다:** Space, ←/→(5초), Shift+←/→(속도), ↑/↓, F, M, B, ?
- **키 겹침 확인:** Udemy 플레이어에서 Shift+?를 누르면 Udemy가 쓰는 키 목록이 나옵니다. 겹치는 키가 있으면 설정 → 단축키에서 바꾸세요.
- **한글 입력 상태:** 키 위치 기준으로 인식하므로 한글 입력 상태에서도 단축키가 동작합니다.
- **탭 밖에서 쓰는 단축키:** Alt+Shift+P(재생/정지), Alt+Shift+←/→, Alt+Shift+S(캡처)는 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다.

## 근거 수준과 한계

이 확장은 Udemy 공식 API가 아닌 **웹사이트 내부 API**를 씁니다. Udemy가 구조를 바꾸면 일부 기능이 멈출 수 있습니다.

| 항목 | 상태 |
|---|---|
| 내 강의 목록 API, 보관 API | 실제 계정에서 확인함 (2026-11-01) |
| 보관 해제(DELETE), 진행 기록 API | 실측하지 못한 추정치. 실패하면 중단하거나 진행률로 추정하도록 처리 |
| 도구 막대, 이중 자막(영상 위 자막 방식), 내 강의 패널 | 실제 Udemy 화면에서 동작을 확인함 (2026-11-13). 영상 아래 자막 띠에 박스로 대체하는 방식은 실제 화면에서 아직 못 봄(그 강의는 자막이 영상 안에 있었음) |
| 커리큘럼·자막 API, 그 밖의 플레이어 DOM 선택자 | 오픈소스 확장 코드 기준. 일부는 실제 화면에서 확인함 |
| 카테고리·언어·자막 필드 | 계정 API가 지원하지 않으면 해당 필터를 자동으로 끔 |

- **테스트 범위:** 모의 Udemy 페이지에서 통합 테스트 107개와 단위 테스트 59개를 통과했습니다. 실제 Udemy 화면 검증은 따로 필요합니다(툴바 아이콘 → Check Page Structure).
- **보호 영상:** DRM이 걸린 강의는 화면 캡처가 검은 화면이 될 수 있습니다.
- **기계번역:** 구글 번역의 비공식 엔드포인트를 씁니다. 언제든 막힐 수 있고, 켜면 자막 문장이 구글로 전송됩니다. 기본값은 꺼짐입니다.
- **제외한 기능:** 영상 다운로드, 코스 전체를 한 번에 완료 처리하기(수료증), 쿠폰 크롤링은 약관·DRM 문제로 넣지 않았습니다.

## 데이터

- 메모, 문장, 태그, 학습 기록, 강의 목록은 **이 브라우저에만** 저장되고 외부 서버로 보내지 않습니다. 기계번역을 켠 경우만 예외입니다(자막 문장이 구글로 전송됨).
- **설정(단축키·옵션)은 예외**로, 크롬 동기화(chrome.storage.sync)로 같은 계정의 다른 PC와 공유될 수 있습니다.
- 설정 → 백업에서 JSON으로 내보내고 가져올 수 있습니다.

## 문제 해결

- **"확장 프로그램이 업데이트되었습니다" 안내가 뜰 때:** 확장을 업데이트하면 이미 열려 있던 Udemy 탭은 새로고침해야 저장 기능이 다시 동작합니다. 저장하지 못한 메모는 클립보드에 복사됩니다.
- **기능이 안 보일 때:** Udemy 탭을 새로고침합니다. 그래도 안 되면 `chrome://extensions`에서 확장을 새로고침합니다.
- **강의 목록이 오래됐을 때:** 패널에서 **데이터 새로고침**을 누릅니다. 자동 갱신 주기는 설정에서 바꿉니다.
- **Udemy 화면이 바뀐 것 같을 때:** 안 되는 기능이 있는 Udemy 탭에서 툴바 아이콘 → **Check Page Structure**을 누릅니다. 확장이 기대하는 화면 요소를 찾았는지(✓/✗)와 못 찾았을 때 멈추는 기능이 나옵니다. 강의 화면에서는 이중 자막이 놓인 방식(`in caption band` 기본 자막 띠 자리 / `over video` 영상 위)과 영상 주변 구조도 함께 나옵니다. "섹션" 항목은 강의 목차를 연 상태에서 점검하세요. ✗가 있으면 **Copy Result**로 내용을 복사해 알려 주세요.
- **상세 로그:** Udemy 페이지 개발자 도구 콘솔에서 `localStorage.setItem('uxk_debug', '1')`을 실행하고 새로고침합니다.
